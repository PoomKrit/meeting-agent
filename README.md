# meeting-agent

อัดเสียงประชุม Microsoft Teams / WebEx → ถอดเสียงด้วย Whisper (`openai-whisper`) → ให้ Claude Code (`claude -p`) วิเคราะห์ transcript แล้วสรุปสิ่งที่ต้องทำแยกตาม ticket

**Note เป็นของพี่ล้วน ๆ:** ใน Mac app ช่อง Note เป็น editor markdown หลายบรรทัด (สัญลักษณ์ยังอยู่แต่จาง ข้อความถูกจัดรูปทันที: หัวข้อ, **หนา**, *เอียง*, ~~ขีดฆ่า~~, `code`, code block, list, `- [ ]`/`- [x]`, `>` quote, link) ⌘B ⌘I ครอบด้วย `**` `*` วางรูปด้วย ⌘V หรือลากมาวาง ข้อความที่วางจากเว็บจะเป็น plain text ไม่มี timestamp บันทึกอัตโนมัติเป็น `notes.md` + `images/paste-N.png` app เขียนไฟล์เองโดยไม่ผ่าน Python และไม่ผ่าน AI LLM เห็นเฉพาะ transcript จาก Whisper เท่านั้น

## ติดตั้ง

```bash
git clone https://github.com/PoomKrit/meeting-agent.git
cd meeting-agent
uv sync
```

ต้องมี: macOS, `ffmpeg`, [BlackHole](https://existential.audio/blackhole/) และ Claude Code (`claude`) ที่ใช้งานได้ (Whisper ใช้ถอดเสียงอย่างเดียว การวิเคราะห์และ next action ให้ Claude Code ทำ)

## ตั้งค่าเสียง (ครั้งเดียว)

ต้องให้เสียงของคนอื่นในห้องประชุมออกไปที่ BlackHole ด้วย ไม่ใช่ออกแค่ลำโพง:

1. เปิด **Audio MIDI Setup** แล้วสร้าง (หรือใช้ที่มีอยู่) **Multi-Output Device** ที่ติ๊กทั้ง `BlackHole 16ch` และลำโพง/หูฟังของพี่
2. ใน Teams / WebEx ตั้ง **Speaker** เป็น Multi-Output Device นั้น (หรือตั้งเป็น output ของ macOS ทั้งเครื่อง)
3. ไมค์ใช้ตามปกติ โปรแกรมจะอัดไมค์แยกอีก track

ใส่หูฟังหรือไม่ก็ได้ ถ้าเปิดลำโพง ไมค์จะรับเสียงคนอื่นซ้ำ แต่บรรทัด "Me" ที่ซ้ำกับ "Others" จะถูกตัดทิ้งตอนถอดเสียง (ดูข้อจำกัด)

ตรวจชื่อ device ได้ด้วย `uv run meeting-agent devices`

## Mac app (หน้าต่างเล็ก + menu bar)

```bash
./macapp/build.sh            # build ด้วย SwiftPM (ไม่ต้องมี Xcode) → ~/Applications/MeetingAgent.app
open ~/Applications/MeetingAgent.app
```

- **เลือกโหมดและไมค์:** แถว "โหมด" สลับระหว่าง ประชุมออนไลน์ (ไมค์ + เสียงประชุม) กับ อัดจากไมค์ (ไมค์อย่างเดียว ซ่อนแถบ Others และปุ่ม Mute) แถว "ไมค์" เลือกไมค์เครื่องหรือไมค์ภายนอกที่ต่ออยู่ (ปุ่ม ↻ อ่านรายชื่อใหม่หลังเสียบไมค์) ค่าตั้งต้นคือไมค์ที่ macOS ใช้อยู่ ถ้าไมค์ที่เลือกถอดออกไป app จะขึ้นข้อผิดพลาดตอนกด Record
- หน้าต่าง: ชื่อประชุม, ภาษา (English ตั้งต้น / ไทย / Auto), ปุ่ม Record / Note only / Stop, แถบระดับเสียง 2 แถบตอนอัด (Me = ไมค์ของพี่, Others = เสียงประชุมจาก BlackHole เขียว/ส้ม/แดงเมื่อดัง/ใกล้แตก, Me เทาเมื่อ mute, ทั้งคู่ลงเป็น 0 ตอน pause), Pause/Resume, Mute me/Unmute me (สองปุ่มหลังขึ้นเฉพาะตอนอัดเสียง), ช่อง Note แบบหลายบรรทัด + วางรูปได้ (จดเอง ไม่ส่งให้ AI, จดต่อได้ระหว่างถอดเสียง), แถบ progress ตอนถอดเสียงและสรุป, รายการประชุมก่อนหน้า
- Menu bar: แสดงเวลาที่อัด/สถานะ, Stop, เปิด Console, เปิดโฟลเดอร์ประชุม ปิดหน้าต่างแล้ว app ยังอยู่บน menu bar
- app เรียก `uv run meeting-agent ...` จาก repo นี้ (path ฝังตอน build) ถ้าย้าย repo ให้รัน `build.sh` ใหม่
- ครั้งแรกที่กด Record macOS จะถามสิทธิ์ไมค์ของ MeetingAgent
- **โหมด Note only:** ไม่จับเวลา ปุ่ม Stop เปลี่ยนเป็น 💾 Save (บันทึกแล้วจบ) ถ้ากด Cancel จะมีป๊อปอัปเดียว "Save Note ไหม?" (Save / ไม่ Save) ถ้ายังไม่ได้พิมพ์อะไรเลย จะไม่เหลือโฟลเดอร์ว่างไว้
- **Cancel (✕) ตอน Record:** ใช้ได้ทุกช่วงตั้งแต่เริ่มอัดจนถึงกำลังสรุป = ยกเลิกการอัด/ถอดเสียง และไม่สรุป/วิเคราะห์ประชุมนี้ มีป๊อปอัป 2 ขั้น: (1) ยืนยันยกเลิกไหม (2) เก็บ Note กับเสียงที่อัดไว้ไหม ถ้าเก็บ ได้ `mic.flac`, `system.flac`, `notes.md`, `images/` (และ `meeting.m4a` / `transcript.txt` ถ้าทำเสร็จก่อนยกเลิก) ถ้าลบ จะลบทั้งโฟลเดอร์ประชุมนั้น กู้คืนไม่ได้ (ลบได้เฉพาะโฟลเดอร์ใน `~/meeting-notes`)
- หน้าต่าง console ลากขยายได้ ช่อง Note ยืดตาม ส่วนรูปที่วางไว้ปรับขนาดให้พอดีความกว้าง (ไม่ขยายเกินขนาดจริง)
- ถ้ากด Quit ตอนกำลังทำงาน app จะถามก่อน ถ้าออกจะไม่มีสรุป แต่เสียงที่อัดแล้วยังอยู่ ใช้ `meeting-agent process <โฟลเดอร์>` ทำต่อได้
- ไม่ใช้ `@State` ใน SwiftUI เพราะ SDK ใหม่ทำเป็น macro ที่ต้องมี Xcode

## ใช้งาน

ใน CLI ระหว่างอัด (พิมพ์ที่ prompt `note>`): ข้อความธรรมดาจะต่อท้าย `notes.md` ตามที่พิมพ์ ไม่มี timestamp ส่วนคำสั่งมีดังนี้

| คำสั่ง | ทำอะไร |
|---|---|
| `/pause` `/resume` | พักการอัดทุก track แล้วอัดต่อ ช่วงที่พักไม่ถูกอัด และ timestamp ไม่นับช่วงพัก |
| `/mute` `/unmute` | ปิด/เปิดเสียงฝั่งพี่ (`Me`) อย่างเดียว ฝั่งประชุมอัดต่อ ช่วง mute บันทึกเป็นความเงียบ เวลาจึงยังตรงกับ track อื่น |
| (flag) `record --levels` | พิมพ์ `[level] <me> <others>` (0-100, สเกล dBFS -60..0) ทุก 0.1 วินาทีให้ Mac app วาดแถบ ปิดอยู่ตั้งแต่ต้นใน CLI |
| `/cancel` | หยุดอัดโดยไม่ถอดเสียงและไม่สรุป ไฟล์เสียงที่อัดไว้ถูกปิดอย่างสมบูรณ์และยังอยู่ในโฟลเดอร์ (ใช้ `process` ถอดเสียงทีหลังได้) |
| `/end` | จบ แล้วถอดเสียง + สรุป (ระหว่างถอดเสียงจะพิมพ์ `[progress] N` เป็นเปอร์เซ็นต์รวมทุก track) |

mute นี้ตัดเสียงที่ app อัด ไม่เกี่ยวกับปุ่ม mute ใน Teams/WebEx (app ตรวจไม่ได้ว่าพี่ mute อยู่ในนั้นหรือไม่) ถ้าพี่ mute ใน Teams แต่ไม่ได้ mute ที่นี่ ไมค์ยังถูกอัดเป็นเสียงเงียบ/เสียงรอบข้างอยู่

```bash
# อัดประชุม + พิมพ์ note ระหว่างอัด (พิมพ์ /end หรือกด Ctrl+D เพื่อจบ) → ถอดเสียง → สรุป
uv run meeting-agent record "Sprint planning"

# ภาษาตั้งต้นคือ English (--language en) ประชุมภาษาไทยหรือไทยปนอังกฤษให้ใส่ --language th
# --language auto ให้ Whisper เดาจาก 30 วินาทีแรกอย่างเดียว ถ้าช่วงนั้นเป็นอังกฤษ ส่วนที่เป็นไทยจะถอดผิดทั้งหมด
uv run meeting-agent record "Daily" --language th

# เลือกไมค์ / device ของเสียงฝั่งประชุม (ใส่ชื่อบางส่วนก็ได้)
uv run meeting-agent record "Daily" --mic "MacBook Air" --system "BlackHole"

# อัดจากไมค์อย่างเดียว (ไมค์เครื่องหรือไมค์ภายนอก) ไม่ต้องมี Teams/WebEx และไม่ต้องมี BlackHole
# ป้ายใน transcript เป็น "Mic" (ไม่แยกว่าใครพูด) ไม่มีการลบเสียงรั่ว เพราะไม่มี track ประชุม
uv run meeting-agent record "คุยในห้อง" --mic-only                    # ใช้ไมค์ตั้งต้นของ macOS
uv run meeting-agent record "สัมภาษณ์" --mic-only --mic "USB Audio"   # เลือกไมค์ด้วยชื่อ (ชื่อตรงเป๊ะมาก่อน ไม่งั้นหาชื่อที่มีคำนั้น)
uv run meeting-agent devices --json                                     # รายชื่อไมค์ (ให้ Mac app ใช้)

# โหมด note อย่างเดียว ไม่อัดเสียง = ไม่มี transcript = ไม่มีสรุป แค่เก็บ notes.md
uv run meeting-agent note "คุยกับ PO"

# ถอดเสียงหรือสรุปใหม่จากโฟลเดอร์ประชุมเดิม (ถ้ามี transcript.txt อยู่แล้วจะไม่ถอดเสียงซ้ำ)
uv run meeting-agent process ~/meeting-notes/2026-11-12_1015_Sprint-planning
```

## ผลลัพธ์

แต่ละการประชุมเก็บไว้ที่ `~/meeting-notes/<YYYY-MM-DD_HHMM>_<title>/`:

| ไฟล์ | เนื้อหา |
|---|---|
| `meeting.m4a` | เสียงประชุมทั้งสองฝั่งผสมเป็นไฟล์เดียว (AAC 96 kbps) เอาไปฟังหรือส่งต่อได้ |
| `mic.clean.flac` | ไมค์ของพี่หลังลบเสียงประชุมที่รั่วเข้าไมค์ (16 kHz) ใช้ทำ `meeting.m4a` และถอดเสียงฝั่ง `Me` ถ้าข้าม (ไม่มีเสียงรั่ว) จะไม่มีไฟล์นี้ |
| `mic.flac` / `system.flac` | เสียงของพี่ / เสียงของคนอื่นในประชุม แยก track (ใช้ถอดเสียง) |
| `notes.md` | note ที่พี่จดเอง (markdown, ไม่มี timestamp) จาก Mac app หรือ CLI ไม่ถูกส่งให้ LLM สร้างเมื่อจดอย่างน้อย 1 ตัวอักษรเท่านั้น |
| `images/` | รูปที่วางใน Note (`paste-N.png`) ลิงก์จาก `notes.md` ด้วย `![](images/paste-N.png)` ลบรูปออกจาก note แล้วไฟล์จะถูกลบตาม |
| `transcript.txt` | `[hh:mm:ss] Me/Others: ...` |
| `summary.md` | สรุปสั้นจาก transcript เท่านั้น (ไม่มีในโหมด note อย่างเดียว): ภาพรวม 3-6 ข้อ, ticket + action items, การตัดสินใจ, คำถามค้าง ปรับรูปแบบหรือความยาวที่ `src/meeting_agent/minutes_prompt.md` |

## ตั้งค่า

- `--whisper-model`: `tiny|small|medium|large-v3|turbo` (ค่าตั้งต้น `turbo`) โมเดลเก็บไว้ที่ `~/.cache/whisper`
- `MEETING_AGENT_MODEL`: model alias ที่ส่งให้ `claude --model` (ค่าตั้งต้น `sonnet` (Sonnet 5.5) ซึ่งไปตาม `~/.claude/settings.json`)

## ข้อจำกัด

- **ไมค์ของพี่ (`Me`) ถอดเฉพาะช่วงที่พูด:** หลังประชุม Silero VAD (รันในเครื่อง ไม่ใช้ LLM) หาช่วงที่มีเสียงพูดใน `mic.flac` แล้วให้ Whisper ถอดเฉพาะช่วงนั้น ช่วงที่พี่ฟังเฉย ๆ (เสียงห้อง, คีย์บอร์ด) ไม่เข้า transcript ไม่ต้องกด Mute me แล้ว `mic.flac` ยังเก็บเต็มไฟล์ และไม่มีงานเพิ่มระหว่างประชุม
- **ลบเสียงประชุมที่รั่วเข้าไมค์ (echo cancellation):** ก่อนทำ `meeting.m4a` และถอดเสียง ระบบใช้ `system.flac` เป็นเสียงอ้างอิงลบเสียงประชุมที่ลำโพงเล่นออกมาแล้วไมค์รับ (Speex AEC ในตัวเดียวทำทั้งลบเสียงสะท้อนและลดเสียงรบกวน) ทำกับ `mic.flac` เท่านั้น ได้ `mic.clean.flac` ส่วน `system.flac` ไม่ถูกแก้ ทำหลังประชุมในเครื่อง ไม่มีงานเพิ่มระหว่างประชุม
  - วัดดีเลย์ระหว่าง 2 track ใหม่ทุก 20 วินาทีแล้วต่อเป็นเส้นตรง เพราะนาฬิกาของไมค์กับ BlackHole เดินไม่เท่ากัน (วัดจากประชุมจริงได้ตั้งแต่ ~0.1 วินาทีถึง 3.8 วินาทีในประชุม 94 นาที)
  - **ข้ามให้เองและใช้ไมค์เดิม** ถ้า `system.flac` ไม่มีเสียงประชุม หรือไมค์ไม่มีเสียงรั่ว (เช่นใส่หูฟัง) หรือเกิดข้อผิดพลาด ปิดเองได้ด้วย `--no-clean` ใช้เสียงเดิมของ `mic.flac` ทั้งไฟล์
  - ถ้าจะทำซ้ำกับประชุมที่ประมวลผลแล้ว ต้องลบ `mic.clean.flac`, `transcript.txt` และ `meeting.m4a` ก่อนรัน `process` (ระบบไม่ทำทับไฟล์ที่มีอยู่)
  - ไม่ได้แยกคนในห้องออกจากเสียงพี่ (ไม่มีเสียงอ้างอิงของคนเหล่านั้น) และเหลือเศษเสียงประชุมเล็กน้อยได้ โดยเฉพาะช่วงเริ่มประชุม
  - ใช้ RAM ราว 1.3 GB ต่อประชุม 40 นาที (ประชุม 94 นาทีราว 2.5-3 GB) และเวลาประมาณ 18 วินาทีต่อ 40 นาที
- **ไม่ใส่หูฟังก็ได้:** เสียงประชุมที่ออกลำโพงแล้วไมค์รับซ้ำ ถ้าข้อความ `Me` ซ้ำกับ `Others` ในช่วงเวลาเดียวกัน (ต่างกันไม่เกิน 2 วินาที, คล้ายกัน ≥ 60%) จะถูกตัดทิ้ง ถ้าพี่พูดทับคนอื่นด้วยคำของตัวเอง จะยังเก็บไว้ ข้อจำกัดคือถ้าพี่พูดทวนคำเดียวกับที่คนอื่นเพิ่งพูดภายใน 2 วินาที บรรทัดนั้นอาจหายไป

- ถอดเสียงหลังประชุมจบเท่านั้น ไม่ใช่ realtime รันบน CPU (`turbo` ใช้เวลาประมาณ 0.6 เท่าของความยาวเสียงต่อ track จากการทดสอบกับคลิปสั้น ประชุมยาว ๆ ยังไม่ได้วัด)
- ช่วงที่เงียบนาน ๆ Whisper อาจใส่คำที่ไม่มีใครพูด (เช่น "Thank you.") ตัวที่มั่วชัด ๆ ถูกกรองทิ้งแล้ว แต่คำสั้น ๆ อาจยังหลุดมา
- แยกผู้พูดได้แค่ "Me" กับ "Others" ยังไม่แยกรายคน
- Whisper มักฟังรหัส ticket ผิด เช่นได้ "PROJ one two three" และเพราะ LLM ไม่เห็น note ของพี่ จึงแก้ให้จาก note ไม่ได้ รหัสที่ไม่มั่นใจจะมี `(?)` ต่อท้ายในสรุป ให้พี่ตรวจเทียบกับ note เอง
- ใช้ `faster-whisper` ไม่ได้ เพราะ proxy บริษัทบล็อก `huggingface.co`
